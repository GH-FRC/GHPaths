## 今日完成

- **GradleRIO 2026 deploy DSL 修正（build.gradle）**：官方模板的 `roboRIO("roborio")` / `frcJava()` 糖方法在 GradleRIO 2026.1.1 + Gradle 8.11 下不存在（实验矩阵 EXP1–11 验证）。根因（javap 反汇编确认）：DeployUtils 2025 的 `DeployExtension` 只有 `targets`/`cache` 两个多态容器，**没有全局 artifacts 块**；FRC artifact 类型注册在各 target 自己的 artifacts 容器上。正确写法：`deploy.targets.create("roborio", RoboRIO){ team=... }.artifacts.create("robotJava", FRCJavaArtifact)` + `deploy.targets.roborio.artifacts.create("deployFiles", FileTreeArtifact)`。随删 2026 线已不存在的 `wpi.java.addJavadocArtifact()/addSourceArtifact()/wpi.sim.enableSimulation()`；`configureExecutableTasks` 收 Jar 任务而非 artifact。
- **vendordeps/PathPlannerLib.json 两处硬伤修正**：① maven 域名错——`3015r2robotics` 应为 `3015rangerrobotics`（ranger），且 mavenUrls 误指向 JSON 本身而非 `/repo`；② artifactId 大小写错——`PathPlannerLib-java` 应为 `PathplannerLib-java`（小写 p）。已用官方 JSON 原样替换（版本 2026.1.2 本身没错，官方源确实有）。
- **首次编译通过**：`gradle compileJava` 0 错误 0 警告，12 个 class；`gradle jar` 出 6.6MB fat jar（WPILib 打包，部署产物形态正确）。Java 源码零修改——"从未编译"雷拆除，写作期静态审查质量合格。
- .gitignore 补 `robot/**/.gradle/`（项目级 Gradle 缓存目录）。
