# 工程日志（engineering-log）

每天一篇，记录当天做了什么、为什么这么决定、下一步是什么。由 AI（Claude）在每次会话中维护，人类随时可读可改。

## 约定

- 文件名与标题同格式：`YYYY.M.D.md`（月、日**不补零**，如 `2026.8.18.md`、`2026.10.3.md`）；
- 一天一篇：当天已有文件则续写（追加小节），不另开新文件；
- 内容用中文，技术名词保留英文；
- 不删旧日志——写错了就在后面更正，保持记录的真实性。

## 每篇结构（可按需增减）

```markdown
# 2026.8.18

## 今日完成
- …

## 决策与依据
- …

## 下一步
- …

## 遗留问题
- …
```
