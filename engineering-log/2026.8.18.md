## 决策与依据

- **锁定 2026 冻结栈**（ADR-0004）：核查确认 WPILib 已于 2026-05 停止 roboRIO 维护、2027 新 DS 不兼容 roboRIO——对不上场比赛的表演项目，冻结即稳定：DS 协议不再逐年漂移，"协议微调"风险降级。

- 审校抓到并修正的代表性错误：Node 版本事实（type stripping 需 ≥23.6，engines 同步提到 23.6）；地理围栏从轴对齐内缩改为外接圆内缩（机器人会旋转，轴对齐会把横行的机器人放出边界）。

## 会话 3：DS 使能链路上线（feat/ds-chain）

### 今日完成

- **multi-DS 从骨架变实体**：包编解码（FRCture 逐字段对照，含位域与电池编码）、LogicalDs（20ms 心跳/500ms 链路超时/三态 estop 闩锁）、独立进程 + 5899 控制 API（UI 断连 2s 宽限自动全停）。
- **fake-robot 加 DS 端点**：UDP 控制包接收 + 状态包回声 + 500ms 看门狗 + estop 闩锁（restartCode 位解除，同构真机恢复路径）。free-run 降级为 `--free-run` 调试旁路。
- **console 接 DS 控制**：使能/失能/急停/解除急停（单机与全组）、电池电压、失联/未使能/运动中/急停状态；multi-DS 断连时清空状态快照。
- **验收（全过）**：`probe:ds` 四关——建链 ✓、使能→运动 ✓（位移 0.41m/1.5s）、**心跳停止 512ms 失效 ✓**、estop 闩锁与解除 ✓；浏览器实测 `kill -9` multi-DS → 全场 ≤1s 冻结（连续采样位姿不变）。

### 决策与依据

- **sim 地址模型改为端口区分**（DS 1500x / 机器人端点 1510x）：macOS 127/8 其余地址默认不可 bind（EADDRNOTAVAIL 实测）；真机模式不受影响——`LogicalDsConfig` 默认仍是"本地 1110 发 + 1150 收"双 socket，sim 以 `statusPort: null` 切到收发同 socket。这层抽象差异隔离在配置里。
- 状态包回程：sim 回控制包来源端口；真机由 roboRIO 固定回 :1150（协议笔记已记）。
- 踩坑两枚：LogicalDs 曾把心跳发往自己的端口而非机器人端口（真机两端同为 1110，sim 分端口后暴露）；ds-probe 的 waitHealth 按值传参读不到回调更新（经典闭包陷阱，裸 socket 对照测试定位）。
- 协议笔记更新：控制包/状态包布局从"待实测"移入"已核查（已实现）"，Phase 0 剩余项收窄为实机抓包对照、TCP 1740 时序、DS 地址认定 3 项。

### 对抗性审查与修复（同分支续，commit d36f13f）

三代理并行审查（安全语义 / 协议字节级 / 代码边界），含 **5 组实测复现**，23 项发现全修：

- **必修 1（安全，实测复现）**：DS 端点在校验包结构前就喂看门狗——任意垃圾 UDP 包（哪怕 1 字节、40ms 一个）就能在 multi-DS 被 kill -9 后维持链路与使能，直接绕过安全验收。修复：完整 6 字节头 + CommVersion 0x01 校验通过才喂狗。
- **必修 2（安全，实测复现）**：`--grace-ms` 拼错静默变 NaN → 宽限期比较恒 false → UI 断连看门狗被无声关闭，机器人可永久保持使能。修复：CLI 参数硬校验（≥250ms 整数）。
- **必修 3（UI，StrictMode 必现）**：useMultiDs 旧 socket 迟到的 onclose 会砸掉新连接的状态，此后急停按钮静默失效。修复：事件按当前 socket 守卫；急停等命令在重连窗口进缓存、onopen 补发。
- 安全加固：estop 位优先于 restartCode（单包 `estop|enabled|restartCode` 不再能一步绕过闩锁）；链路超时把 enabled 降级为 disabled（断连期间下的使能不再于恢复瞬间自动生效）；控制 API 校验 Origin（任意网页不能再连 5899 发 clearEstop）。
- 协议修复：robotAddress 经 dns.lookup 解析后再过滤状态包（mDNS 名直接比较必失配——真机主路径修复）；clearEstop 的 restartCode 位保持到机器人回声 estop=false（≤3s 上限，单包易丢）；状态包按 FRCture 语义回声模式位。
- 探针加固：probe 防 `--free-run` 误通过；ds-probe 看门狗 ≤1.1s 硬判据。
- 审查员核过为安全的路径（摘）：estop 闩锁在 disable/宽限期/优雅关停/kill -9 下均不解除；心跳周期无跳过；SIGINT/SIGTERM 先全 disable 再退出。

复验：typecheck 0 错；probe 与 probe:ds 全过（看门狗 561ms）。教训入册：**安全链的每个参数入口都是攻击面**（一个 CLI 拼写就能关看门狗）；**sim 端点必须比真机更"多疑"**（校验从第一字节开始）。
