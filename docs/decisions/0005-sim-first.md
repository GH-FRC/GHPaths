# ADR-0005：仿真先行（无硬件开发回路）

日期：2026-08-18 · 状态：已接受

## 决策

`sim/fake-robot` 提供「NT4 发布 + DS 端点模拟」的模拟机器人；console / multi-DS 的日常开发先对 sim，实机验证集中在 Phase 0/1 节点做。

## 理由

- 硬件不常在手边，DS 端点模拟同时是协议实现的第一个测试夹具（回环验证）；
- 与 CheesyArena Lite 的 `-dev` 标志同思路（官方社区同样支持无机器人开发）。

## 硬约束

模拟的 DS 端点必须实现与真机一致的使能语义（**停包即失效**），否则测不出安全问题——这是本 ADR 存在的意义，不是可裁剪的细节。
