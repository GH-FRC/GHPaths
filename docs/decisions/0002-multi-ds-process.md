# ADR-0002：multi-DS 做成独立进程

日期：2026-08-18 · 状态：已接受

## 决策

multi-DS（FRC DS 协议心跳与使能控制）作为独立 Node 进程运行，UI 经 localhost WebSocket（:5899）控制。

## 理由

1. **安全域隔离**：UI 崩溃/重启不影响心跳；反向地，UI 断连超过宽限期（默认 2s，Phase 0 校准）→ 全部自动 disable——双向兜底；
2. **换代预留**：2027+ Systemcore 的 DS 架构不同（闭源），协议实现整体可替换（报告 §5.4）；
3. UI 框架更替免疫；排练时可 headless 运行。

## 安全不变量（改动 multi-ds 必须保持）

- 进程停止 = 心跳停止 = 全机失效。**不许有任何"优雅保持使能"的逻辑**；
- estop 只能显式 clear，任何自动逻辑不得复位；
- 宽限期 disable 可调时长、不可关闭。
