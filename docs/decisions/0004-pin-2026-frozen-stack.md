# ADR-0004：锁定 2026 冻结栈

日期：2026-08-18 · 状态：已接受

## 背景

核查确认：WPILib 已于 **2026-05-02 停止 roboRIO 侧维护**；2027 起为 Systemcore 新控制体系（新 DS 闭源、不兼容 roboRIO）。表演项目不上场比赛，冻结栈意味着 DS 协议与机器人软件栈**不再逐年漂移**。

## 决策

- 机器人镜像、WPILib、PathPlannerLib 等 vendordep **全部钉 2026 版**；
- 升级属于主动决策，必须附带协议回归测试（三态：使能 / 停包失效 / estop）；
- multi-DS 协议实现按 2026 实机抓包定案，不追逐"新赛季协议"。

## 后果

- multi-DS 一次做对，长期稳定服役；
- 新购 Systemcore 机器人时重开 ADR 评估迁移。
